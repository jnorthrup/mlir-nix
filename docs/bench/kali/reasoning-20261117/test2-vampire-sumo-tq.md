## Findings about the pipeline (each checked in the logs named)

- Vampire 5.1.0 has no `--output_axiom_names`; SigmaKEE's Vampire.java and tqsp-ci.yml still pass it, and 5.1.0 stops with
  `User error: output_axiom_names is not a valid option` (first attempt, since rerun without it). Its TPTP proof names every
  input formula in `file(...,'name')` anyway.
- SigmaKEE's TFF of Merge.kif does not load in Vampire 5.1.0: `kb_SUMO_1` applies `$difference` to `0.0` and an `$int`
  variable ("not used with a single sort"), and session TFF files declare constants with '-' (`s__Value20-1 : $i`) that
  the formulas spell `s__Value20_1` ("wrong number format" / ": expected"). Every TFF problem, SigmaKEE's and upstream
  TQSP's (which include the same SUMO.tff), is InputError. The tfffix sets drop kb_SUMO_1 and rename the declarations.
- SigmaKEE drops test assertions (logs/final/ua-check.tsv, sigma-*/TQDump*.out, sigma-top/capture1/*.TQDump.out):
  for a TFF query `KB.tell()` writes the assertions in FOF (`language = fof`), so they never reach the TFF problem;
  in one JVM the tell language follows the previous query, which also lost TQG34's two FOF assertions after TQG33 (TFF);
  the modal THF tests TQC1, TQC2b, TQC2b2, TQC3 reach Vampire without their assertions. TQC2's translated conjecture
  (`? [W1,W2:w, B:(w>$o)] : (accreln1(Permission,W1,W2) => B(W2))`) is valid by itself, so its Theorem does not use the test.
- Upstream tests/TQSP translations are older than the .kif.tq files: TQG10S has BananaSlug10_1 and the rule without
  `instance ?A Invertebrate`; Vampire times out on it while SigmaKEE's current translation is a Theorem in 0.47 s.
- SigmaKEE gives different formulas the same TPTP name (e.g. two `kb_SUMO_s1375013785_1` in TQG26); lean-auto rejects
  duplicate hint terms ("Auto does not accept duplicated input terms"), so tptp2lean.py numbers repeated names.
- A SigmaKEE JVM that finds KBs/SUMO_plain.thf current blocks 600 s in TPTPGenerationManager.waitForTHFPlain
  (TQC1 601.6 s, TQG51b 609.2 s); deleting SUMO_*.thf before the JVM starts avoids it.
- With the 9.8 MB TFF KB included, pure-arithmetic conjectures whose proofs use no axiom (NUM1 `~(-1 = 0)`, TQG11
  `12 = 3*4`) take 47-60 s in the CASC portfolio; NUM2 was a Theorem in 52.7 s in one run and a Timeout at 60 s in another.
- The hammer failed on NUM1 `¬((-1 : Int) = 0)` and NUM2 `¬((-1 : Int) = 1)` (NUM2 from the 300 s rerun, where Vampire
  proved it in 53.9 s; logs/hammer/tfffix-sigma-t300/NUM2.out): its exported problem was Satisfiable ("The exported
  premises do not imply the exported goal"), so the negative Int literal loses its meaning on export; `12 = 3 * 4` (TQG11) is proved. $real problems (TQG19/20/21) are not encodable here: Lean core has no reals (Mathlib needed).
