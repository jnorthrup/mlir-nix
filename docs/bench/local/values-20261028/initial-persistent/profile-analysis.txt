Next conservative work suggested by evidence, not implemented here:
Keep arbitrary persistent/projection returns. Before widening callbacks, avoid
admitting partial saturated value plans that compete with an existing complete
pointer selector, or add explicit safe empty-result recipes covering their
other branch. A generic recipe would need fresh-result/identity and shallow
grace rules, not permission to return local temporary SSA storage. A bounded
post-oracle yield sample / rolling deopt budget can also keep mixed low-yield
plans from occupying compile slots indefinitely. Preserve source positions,
laziness, one oracle execution and active native-run lifetime pins.
