Accounting without double-counting:
Value completions include both persistent cells and empty recipes and are a
subset of existing boolean_completions. Curried value counts are subsets too.
Final NixOS: 227,199 value results = 164,475 cells + 62,724 empty recipes.
Final nixpkgs: 290,291 = 58,862 cells + 231,429 recipes. Grace is included
(30 / 18 results). Bool cells count as values; no per-type runtime histogram
exists. The gate validates all supported WHNF types, but profile totals must
not be described as counts of exclusively non-Bool values.
Pointer selector calls fall 128,048 -> 45,983 (-82,065) and 233,126 -> 223
(-232,903) versus OFF. These reductions equal trusted new optional-shape calls:
  NixOS: 82,068 - 3 = 82,065.
  nixpkgs: (145,387-3) + (55,972-3) + (31,553-3) = 232,903.
Those calls replace an existing native pointer route. Do not add value,
curried and pointer completions or semantic frames_saved as separate savings.
All nixpkgs value completions are visible in printed rows. NixOS prints 170,569
of 227,199, leaving 56,630 unattributed. Profiles show only the 60 highest-call
unary/curried rows, not deopt rankings. NixOS reaches the 4,096 unary profile cap
with 214,363 dropped profile calls; nixpkgs has 3,537 entries, none dropped.
The aggregate statistics themselves are not truncated.

Retirement frees machine code but does not refund compile attempts. All JIT
arms also reach the separate 256 curried candidate cap. NixOS's previously
productive systems/default.nix:46:41 and customisation.nix:254:24 curried
entries now stop at 1,024 calls with zero completion (OFF: 52,990 and 182);
asserts.nix:50:15's previous 12,513 completions are absent from the three final
compiled curried entries. Nixpkgs retains its systems/asserts/customisation
plans, while the modules.nix:273 value projection remains uncompiled.
These patterns are consistent with budget/admission displacement, not proof
of a per-entry rejection reason: compile order/refusal causes are not logged.
