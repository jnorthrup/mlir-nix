  21.1.8 at the lock's nixpkgs (`e513db7`), where master is built with 22 and 23. Now `flake.nix` keeps tomberek's outputs (`formatter`,
  `packages`, `devShells`, every system of `legacyPackages`, the same lock) and its package is `default.nix`'s derivation, so there is one
  recipe for `nix build` and `nix-build`:

    correct form". MLIR 22's IRDL loader has no case for an `irdl.base` inside an `irdl.any_of` (`getBases` ends in `llvm_unreachable`, which
